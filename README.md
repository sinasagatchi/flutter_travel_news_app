## About

Flutter Travel News App is a travel-focused news application built with Flutter.

The project features a modern and minimal interface designed to provide a comfortable reading experience across Android and Web platforms.

It supports English and Turkish languages, Light and Dark themes, and includes application features such as content search, bookmarks, sharing, and navigation.

Developed with the help of free packages published by other developers.

## Features

- **Two Themes:** Light and Dark modes.
- **Localization:** English and Turkish language support.
- **Search:** Search through available local content.
- **Bookmarks:** Save and manage bookmarked content during the app session.
- **Share:** Share content using the platform's native sharing functionality.
- **Travel News:** Browse news and open article details.
- **Navigation:** Navigate through the existing application sections.
- **Responsive Layout:** Designed for Android and Web.
- **Scrolling:** Scrollable content across supported screens.
- **Image Fallback:** Fallback handling for unavailable network images.

## Getting Started

### Requirements

- Flutter SDK
- Dart SDK
- Android Studio or another Flutter-compatible development environment

### Installation

Clone the repository:

```bash
git clone https://github.com/sinasagatchi/flutter_travel_news_app.git
```

Navigate to the project directory:

```bash
cd flutter_travel_news_app
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```

### Run on Web

```bash
flutter run -d chrome
```

### Build for Android

```bash
flutter build apk
```

### Build for Web

```bash
flutter build web
```
